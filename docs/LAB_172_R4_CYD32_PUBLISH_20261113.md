# SquachEmit LAB 172-R4 — CYD 3.2 ST7798 — Live LCD Mirror + Remote Touch

## Firmware source

This LAB branch carries the tested SquachEmit CYD 3.2 firmware source from PR #37 commit `8e987b152c59f7901a16606771b594e556923ab5` and its current LAB v0.4 Windows Workbench interface. The previous LAB branch revision is preserved in history. This update changes the CYD 3.2 LAB firmware; it does not modify SquachWatch, merge any PR, create production tags, or change the stable v1.1.0 release.

## What is new since LAB build 192a9699

- Real RGB565 LCD pixels captured from the physical ST7798 controller when GRAM readback is supported.
- Nonblocking two-row LCD transport plus changed-row updates, with full-frame resynchronization after dropped frames.
- Remote mouse taps, holds and movement use the existing native CYD touchscreen event path.
- Disconnect or unsupported TFT readback displays a clear error rather than a simulated screen.
- All 172 case profiles and native 3–30-second transmitter timing remain.

**Hardware validation required:** This source compiles and host tests passed on PR #37, but screen readback and color fidelity have not been verified on a physical CYD 3.2. Use matching Windows Workbench LAB v0.4.0. Connect at 115200, send MIRROR BAUD 2000000, reconnect at 2000000 without power cycling, then use the live screen. Some adapters reset the board when reopened.

Release channel: LAB only. Always verify exact firmware commit in the web installer and use the four-part SHA-256 integrity preflight.
