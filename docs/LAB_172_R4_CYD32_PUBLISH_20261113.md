# SquachEmit CYD3.2 LAB R7 — Native Interactive Windows UI, No Screen Grab

This existing LAB branch contains the firmware source from SquachEmit PR #37 commit `7342a7ac3d8f7ce2d662808fbd5ad786e32a5a35`.
This publishing-only commit changes the LAB notes, not firmware source or any RF test algorithm. Existing LAB branch history stays intact.

**R7 replaces screenshot mirroring with a desktop-owned UI.** The CYD 3.2 no longer reads TFT GRAM, generates RGB565 frame rows, sends screenshots, or switches UART to 2 Mbps. The firmware responds to `UI ON/OFF/GET` and `UI TOUCH x y DOWN|MOVE|UP`, returning `UI READY` and compact `UI STATE` records at 115200. These contain the actual page, selected profile, category, 3–30-second TX time, active/suite status, countdown, calibration, pet and device uptime.

The Windows Workbench **R7 v0.5.0** independently draws the 320×240 interface, synthwave background, native menus and procedural Squachy with Canvas2D on the PC. It maps clicks/drags/holds into the device's original native touch handling. Physical screen navigation, including touch on the board, updates the EXE from subsequent state messages. No old pixel-based LCD readback is used for SquachEmit.
