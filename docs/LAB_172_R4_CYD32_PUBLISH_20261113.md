# SquachEmit CYD 3.2 LAB R5 — Live Physical LCD + Remote Touch Diagnostic

## Exact source and safety
Source reviewed and CI-validated in SquachEmit PR #37: `fa0d81b6cc118e39cd9b27d41e80a98b1c918caa`.
This pre-existing CYD 3.2 LAB branch carries the same firmware source and
Windows Workbench R6 v0.4.2 assets. No PR is merged, no stable release is
replaced, and no SquachWatch code is changed.

## Key changes after LAB R4
- Physical RGB565 LCD capture is permitted during touchscreen calibration.
- ST7798/7789-compatible SPI TFT read frequency lowered to 6 MHz to help
  real GRAM readback succeed.
- New `MIRROR DIAG` reports LCD size, calibration, UART baud and pixel variation.
- `MIRROR FRAME` works at 115200 baud when port reopening resets the CYD,
  but first full frame may take 20–40 seconds. For live animation, use 2 Mbps.
- The Windows Workbench waits for actual `MIRROR READY` rather than trusting
  a USB write alone and never invents a fake screen when TFT readback fails.
- The EXE automatically pauses the SquachWatch receiver screen when a
  transmission begins, switches to real exact-MAC LOG observations, and
  allows user-requested RF tests. The independent SquachEmit LCD can
  continue mirroring throughout tests.
- Automatic 172-case suite preserves its real receiver baseline requirement.
- 172 bounded synthetic BLE/Wi-Fi test cases and four-segment SHA-256 flash
  verification are unchanged.

Physical ST7798 TFT GRAM support, full screen color fidelity and mouse
interaction remain hardware verification gates. A failed readback must report
an error, not a simulated LCD image. Production v1.1.0 stays unchanged.
