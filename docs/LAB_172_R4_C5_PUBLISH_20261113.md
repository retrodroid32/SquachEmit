## Firmware source and provenance

Source firmware: 0b7a2edcd8f7de6fc45ad320a7c0b9f6fa2e8974 (SquachEmit Windows Workbench PR #37).
This branch changes documentation only; its firmware, signals, radio algorithms and display logic match the source firmware at 0b7a2edcd8f7de6fc45ad320a7c0b9f6fa2e8974.

## Changes from older 172-R3

172 synthetic controlled RF test cases, stable unique transmitter identities, named scenarios, current 3–30-second TX time controls where supported, and experimental CYD 3.2 USB RGB565 LCD mirror and remote touch functionality. The LCD mirror is only implemented for the CYD 3.2; C5 does not support its LCD screenshot protocol.

These builds are development LAB firmware. Physical Wi-Fi/BLE reception, LCD readback, UART 2Mbps handoff and touchscreen mirroring must be validated on the specific boards before production use. The host's ACTUAL receiver classification is not proof of detection without exact-MAC correlation and valid baseline. No new radio transmissions or changes to approved v1.1.0 are introduced by this documentation-only branch.

This branch exists to use SquachEmit's existing **successful lab CI -> GitHub Pages LAB firmware** pipeline without merging PRs, tagging, or changing production stable firmware. Flash only on exact target hardware and use the installer SHA-256 preflight.
