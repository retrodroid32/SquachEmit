03 / VALIDATION PROTOCOL

HARDWARE CHECKLIST

01. VERIFY

Choose the exact PCB: Waveshare C5 2.8" (ST7789/CST3530) or CYD 3.2" ESP32-2432S032R (ST7798-compatible/XPT2046). Their firmware is NOT interchangeable.

02. FLASH

Flashing SquachEmit replaces any SquachWatch firmware on that physical CYD. Back up first; use a second board as receiver.

03. GENERATE

Run BLE-META-UUID, WIFI-AXON, BLE-NEG-UUID, then SUITE in a controlled RF environment.

04. SCORE

Record each actual alert separately on the 2.8-inch and 3.2-inch SquachWatch CYDs; review missed and false detections.
